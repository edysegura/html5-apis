SSE Using HTMX

A responsive SSE demo with HTMX and PicoCSS v2. The message box below updates in real time from the `/events` stream.

Live Server-Sent Events

Contents of this box will be updated in real time with every SSE message received from the chatroom.

How it works

HTMX establishes the SSE connection and swaps incoming messages into this element. PicoCSS keeps the layout responsive across mobile, tablet, and desktop.

Make sure your SSE server is on the same origin or returns proper CORS headers for cross-origin usage.
